# 模拟盘（A6）— 功能文档

**版本**: v1.0（2026-10-13） | **状态**: 全部交付并验证通过（引擎 + API + 前端 + 浏览器实测）
**范围**: 独立账户式模拟盘——多标的共享资金池、固定比例复利、策略时间线、止损线/到期清算、确定性重放与复盘报告
**上游依据**: 开发计划"任务化"与"模拟台账"思想的延伸（计划外增强，用户需求："台账升级为可自设资金/策略/周期的模拟盘，自动买卖、亏光或到期结束、出复盘报告"）
**口径声明**: 成本模型与实盘台账（ledger）同源；纯函数按需重放（无常驻任务）；同一数据必得同一结果（确定性）。

---

## 0. 概述

模拟盘 = **一个独立账户**：自设初始资金、每笔仓位比例、止损线、起止时间与多标的（同市场），系统按规则 DSL 自动买卖；权益跌破止损线、到期或手动结束即冻结清算；随时出复盘报告（确定性统计 + 归因 + LLM 建议，可关）。

与全局台账（P1，`paper_position`）的关系：**各自独立**——台账跟随扫描器推送的全局信号，模拟盘是用户自设的独立沙箱；两者共用同一套成本模型与 PIT 成交口径，互不影响。

| 交付物 | 代码位置 | 关键入口 |
|--------|----------|----------|
| 两表 | `db/init/01_init.sql`（`sim_account` / `sim_change`） | 自动建表 |
| 供数 | `backend/app/models/db.py`（账户/变更 CRUD） | `db.get_sim_account` 等 |
| 引擎 | `backend/app/engine/sim.py` | `run_account` / `review_stats` / `llm_review` |
| API | `backend/app/api/routes.py`（`/api/sim*`） | `POST /api/sim` |
| 前端 | `frontend/app/sim/page.tsx` + 导航"模拟盘" | 列表/新建/详情/调整/结束/删除/复盘 |
| 验证 | `backend/scripts/verify_sim.py`（7 场景 39 项） | 离线可跑 |

核心决策：**同市场共享资金池**（单盘 crypto USDT / A股 CNY 不混）；**策略快照**（入库时快照 DSL，重放不随规则库变动）；**按需重放**（无定时任务，打开详情即确定性重算）；**止损线优先**（触线当根信号不再执行）。

## 1. 语义与时间口径

- **起点**：`start_days_ago=0` → 从创建时刻起逐根跟随；`>0` → 过去起点，创建即回放出 `[起点, 现在]` 的完整结果（同一套引擎，状态仍 `active` 继续跟随）。
- **到期**：`end_ts = 创建时刻 + duration_days 天`（注意：**从创建时刻起算**，非从起点算）；留空 = 不限。已到期（`expired`）只会随时间自然流逝出现（重放时 `min(now, end_ts)` 截断数据）。
- **结束三态**：`stop_loss`（权益 ≤ 初始资金 ×(1-止损线%)，强平）/ `expired`（时间到期，按最后收盘价清算）/ `manual`（手动结束按钮，同清算口径）。
- **数据截止**：`cutoff = min(now, end_ts)`——重放永远看不到未来数据（无未来函数）。
- **策略时间线**：`sim_change` 按 `effective_from`（**下一根 bar 起生效**）分段；换策略后旧仓位由新策略的出场条件管理（持仓状态跨段延续）；已结束的盘不可再调整（422）。
- **展示层**：起止/交易时间/时间线均为北京时间（+8）；存储 UTC（与全局口径一致）。

## 2. 引擎口径（`sim.run_account`）

- **多标的共享资金池**：所有单元同步在一条时间轴上推进（marks = 各单元 bar 时间并集）；每个 unit 同时最多 1 个持仓。
- **定仓（固定比例 · 复利）**：`每笔名义 = min(当前权益 × size_pct%, 可用现金)`；现金不足按比例缩减；`qty = 名义 / 入场有效价`。
- **成本模型（与 `ledger._settle` 同源常量）**：
  - 币圈：taker 单边 0.05%（`FEES`）+ 滑点单边 5bps；
  - A股：佣金万 2.5（最低 5 元/笔）+ 印花税千 0.5（仅卖出）+ 滑点单边 5bps。
- **止损线**：每根 bar 收盘**先**核权益 ≤ `初始资金×(1-stop_loss_pct%)` → 按最后收盘价全部强平（`stop_loss`），当根信号不再执行；`stop_loss_pct=0` 关闭。
- **预热**：起点前 `PRE_BARS = WARMUP_BARS + 50` 根用于指标/cooldown 收敛（事件仅取起点之后）；数据不足（< WARMUP_BARS+2）的单元跳过。
- **确定性**：纯函数按需重放；`equity` 序列降采样至 `max_points=1500` 点（首尾保留）。
- **指标输出**（`_metrics`）：笔数 / 胜率 / 盈亏比（无亏损=inf，JSON 层转 null）/ 均收益 / 总盈亏 / 收益率（对初始资金）/ 最大回撤 / 费用合计 / 平均持仓小时 / 持仓暴露%。

## 3. 数据模型（两表）

- **`sim_account`**：`name / market(crypto|cn) / init_cash / size_pct / stop_loss_pct / start_ts / end_ts(可空) / status(active|finished) / units_json / created_ts`。
- **`sim_change`**：`account_id(CASCADE) / unit_idx / effective_from / name / dsl_json / created_ts`；索引 `(account_id, unit_idx, effective_from)`。策略快照保证重放确定性（不随规则库变动）。

## 4. API（`/api/sim*`）

| 方法/路径 | 说明 |
|-----------|------|
| `POST /api/sim` | 创建（201）→ `{id,name,market,start_ts,end_ts,units[{symbol,timeframe,strategy}]}`；校验：混市场 422、`size_pct<=0` / `stop_loss_pct>=100` 422、重复单元 422、无行情数据 404、`rule_id` 与单元错配 422 |
| `GET /api/sim` | 列表（含 units 全字段） |
| `GET /api/sim/{aid}` | 详情 = 元信息 + `db_status` + 单元策略时间线 + `result`（确定性重放，含 equity/trades/open_pos/metrics） |
| `POST /api/sim/{aid}/change` | 调整策略（`unit_idx` + `rule_id` 或 `text` 二选一，text 走 rule_gen 生成草稿）；已结束 422 |
| `POST /api/sim/{aid}/finish` | 手动结束（清算 + status=finished） |
| `DELETE /api/sim/{aid}` | 删除（CASCADE 清变更） |
| `POST /api/sim/{aid}/review?llm=1|0` | 复盘：`{status,end_reason,stats,notes,llm{text,ok,error}}`；`stats` 为确定性统计（总览/按标的/按策略段/归因要点），LLM 失败自动降级（`llm.text=null` + error） |

策略选择：`rule_id` → 规则库存量 DSL 快照；缺省 → `sma_520` 模板；`text` → rule_gen 生成（同 P3）。

## 5. 复盘报告

- **确定性层（`review_stats`，不依赖 LLM）**：总览指标 + 按标的聚合 + 按策略段聚合（仅真实切换时输出段对照）+ 归因要点（最大亏损标的、费用占亏损比、回撤/暴露、止损笔数、空交易提示）。
- **LLM 层（`llm_review`，可关）**：explain 档模型（json_mode，≤300 字）——先归因再 2~3 条可执行改进建议；违禁表述过滤（保证/必涨/稳赚/梭哈…）与失败降级（只给确定性统计，不阻塞）。

## 6. 前端（`/sim`）

- **列表**：名称/市场/初始资金/仓位%/止损线/状态/起止（两行：起点 ↔ 终点或"不限"）/标的多选汇总/操作（详情·结束·删除，Popconfirm 确认）。
- **新建**：标的（自选池联动）+ 周期 + 策略（规则库联动，可选，缺省模板）+ 初始资金/仓位%/止损线/起点（N 天前，0=现在）/周期限制（N 天后到期，留空不限）。
- **详情**：权益曲线（lightweight-charts 面积图，北京时间刻度）+ 指标 + 持仓中 + 交易明细（价格按币种自适应小数位）+ 策略时间线 + 复盘区（Alert 摘要 + 总览/按标的/按策略段表格 + 归因要点 + LLM 建议）+ 调整策略表单。
- 页面顶部口径说明卡：共享资金池 / 复利 / 同口径成本 / 起点语义 / 止损与到期 / 按需重放。

## 7. 验证基线（2026-10-13）

- **`verify_sim.py`（7 场景 39 项全 PASS）**：①手算复算（qty/pnl/成本/复利定仓逐笔核对）②止损线触线（时点=跌首根、强平无残留、终值≤线）③到期 expired 清算（清算价=最后收盘）/ 手动 manual ④策略切换（生效点前事件过滤、跨段持仓延续）⑤确定性重放（两次逐字段一致）+ 复盘统计 ⑥API 全链路（创建/列表/详情/调整快照/时间线/降级复盘/结束/删除 404）⑦边界（混市场 422、size_pct=0 422、stop=100 422、重复单元 422、无数据 404、规则错配 422）。
- **运行中 API 冒烟（19 项全 PASS）**：创建 30 天回放盘 → active/trades=33/marks=719 → 复盘（llm=0）→ 活动盘调整时间线 2 段 → finish→manual → 结束后 change 422 → delete→404。
- **浏览器实测**：创建（列表数据/格式化全对）→ 详情（15 笔、胜率 33.33%、盈亏比 1.71、收益率 1.46%、回撤 -1.81%、费用 45.7、暴露 39%、价格小数位、北京时间）→ 复盘显示 → 策略调整（时间线 2 段）→ 结束（状态/按钮变化）→ 删除（行消失）；列宽修复后各列宽度复核（标的列 34→198px）。
- **回归**：verify_ledger / verify_api 全绿；全局台账不受影响。

## 8. 已知边界

- 单盘限同一市场（crypto/A股不可混）；每个 unit 同时最多 1 仓；不支持做空/杠杆（现货口径）。
- A股日线 `PRE_BARS` 预热按 1d 计（起点需有足够历史）；开盘跳空/停牌不特殊处理（成交价=bar 收盘价）。
- 复盘的策略段聚合按 `(unit, strategy)`；若规则被删除，时间线仍按名称展示（快照 DSL 不受影响）。
- 详情重放为**按需同步**计算（多单元长窗口时耗时随数据量增长）；equity 视图恒 ≤1500 点。
- 删除模拟盘不回收历史（无软删）；未到期且未触线的盘无自动清理。
